# 🌐 Cisco Packet Tracer – Network Topology

## 📌 About the Project

This project is a network design and simulation built using **Cisco Packet Tracer**. It includes multiple interconnected LANs with both wired and wireless devices, connected through routers and switches.

The goal was to practice networking concepts, configure routing protocols, and understand how different networks communicate with each other.

## 🏗️ Network Components

The topology includes:

- 🖥️ Desktop PCs
- 💻 Laptops
- 📱 Smartphones and tablets
- 🔀 Cisco switches
- 📡 Wireless access points
- 🌐 Multiple routers
- 🗄️ A centralized server
- ☁️ Internet connectivity

## ⚙️ Routing Protocols

I used two dynamic routing protocols in this project:

- **OSPF (Open Shortest Path First):** Used for routing outside the Internet-facing network.
- **RIP (Routing Information Protocol):** Used inside the internal network.

This setup helped me practice working with different routing protocols and understand how routers exchange routing information.
